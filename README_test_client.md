# 测试客户端 (Test Client)

Client code is generated by AI.

这是一个简单的客户端程序，用于测试 KCP 服务器的房间连接功能。

## 功能

- 支持指定房间ID连接服务器
- 如果不指定参数，默认创建新房间 (room_id = 0)
- 支持加入已存在的房间
- 自动处理 KCP 协议通信
- 发送测试的 Lobby 消息

## 构建

运行构建脚本：

```bash
./build_test_client.sh
```

或者手动构建：

```bash
# 生成 protobuf 文件
cd src/message
./proto2cpp.sh
cd ../..

# 构建客户端
mkdir -p build_test_client
cd build_test_client
cmake -f ../CMakeLists_test_client.txt ..
make -j$(nproc)
```

## 使用方法

### 基本用法

```bash
# 创建新房间（room_id = 0）
./test_client

# 加入指定房间
./test_client 1001
```

### 详细说明

- **无参数**: 创建新房间，服务器会分配一个新的房间ID
- **指定房间ID**: 尝试加入已存在的房间，如果房间不存在则连接失败

## 测试逻辑

客户端会按照以下步骤进行测试：

1. **发送 HelloMessage**: 
   - conv = 0 标识这是初始连接消息
   - 包含指定的 room_id

2. **接收 RoomMessage**: 
   - 解析服务器返回的房间信息
   - 显示房间ID、玩家ID、角色信息等

3. **发送 LobbyMessage**: 
   - 模拟玩家在大厅中的操作
   - 设置角色类型和准备状态

## 服务器交互

根据 `kcp_server.cpp` 中的逻辑：

- **room_id = 0**: 服务器创建新房间，分配新的玩家ID和conv ID
- **room_id > 0**: 服务器尝试将玩家加入指定房间
- **房间不存在**: 服务器返回 `is_join = false` 的 RoomMessage

## 注意事项

1. 确保服务器正在运行（默认端口 8888）
2. 确保 protobuf 文件已正确生成
3. 需要先启动服务器再运行客户端
4. 客户端会在2秒后自动退出

## 排除故障

如果遇到编译错误：
- 检查是否安装了 protobuf 开发包
- 确保 protobuf 文件已生成到 `src/message/gen/` 目录
- 检查 CMake 版本是否 >= 3.10
